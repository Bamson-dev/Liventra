# Changelog

All notable changes to Liventra will be documented in this file.

## [v1.0.0-rc1] - 2026-07-30
### Added
- Complete initial architecture release (PRD-001 through PRD-019).
- Central EventBus & Event-Driven Architecture.
- Authoritative Session, Simulation, and Timeline Engines.
- Video Engine supporting MP4, HLS, and Bunny.net stream providers.
- Registration & Identity Engine with single-use join tokens and waiting room states.
- CTA Engine with real-time countdowns and offer urgency triggers.
- Live Chat Engine with moderator pinning and emoji reactions.
- Analytics & Event Intelligence Engine with funnel tracking and engagement snapshots.
- Admin Studio & Visual Timeline Editor.
- Security Platform with SAML 2.0, audit logging, and rate limiting.
- Public API Gateway & Idempotency Engine.
- Multi-Channel Notification Platform (Email, SMS, WhatsApp, Push, In-App).
- Observability & Operations Platform with correlation IDs and health probes.
- Performance & Scalability Platform with L1/L2 multi-level caching and worker pools.
- Plugin SDK & Marketplace Platform with isolated sandboxing and digital signature verification.
- Enterprise Multi-Tenant Platform with organization switcher, workspaces, and white-labeling.
- Playwright E2E browser test suite and GitHub Actions CI/CD workflows.
